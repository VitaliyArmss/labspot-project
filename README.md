# LabSlot

> Система бронирования оборудования, лабораторий и рабочих мест с каталогом ресурсов, управлением бронированиями и административной панелью.

## О проекте

LabSlot — учебный full-stack проект, предназначенный для организации бронирования ресурсов в университете, лаборатории или небольшом техническом центре.

Приложение позволяет пользователям просматривать доступное оборудование и помещения, выбирать временные интервалы и управлять своими бронированиями. Администратор может управлять каталогом ресурсов.

Основной фокус проекта — практическая реализация задач, возникающих в приложениях с общими ресурсами и ограничениями по времени:

- разработка REST API на ASP.NET Core;
- разделение frontend и backend;
- проектирование реляционной модели данных;
- аутентификация и разграничение прав доступа;
- проверка пересечения временных интервалов;
- работа с PostgreSQL через Entity Framework Core;
- обработка ошибок и валидация запросов;
- независимое развёртывание frontend и backend;
- настройка reverse proxy и production-конфигурации.

## Возможности

### Каталог ресурсов

- просмотр доступного оборудования и помещений;
- карточки ресурсов с описанием и характеристиками;
- поиск и фильтрация;
- просмотр доступности ресурсов.

### Бронирования

- создание бронирований на выбранную дату и время;
- просмотр собственных бронирований;
- отмена бронирования;
- проверка занятости временных интервалов;
- серверная проверка конфликтов бронирования.

### Пользователи и авторизация

- регистрация и вход;
- JWT-аутентификация;
- разграничение пользовательских и административных операций;
- проверка прав доступа на backend.

### Администрирование

- добавление и редактирование ресурсов;
- управление доступностью ресурсов;
- просмотр и управление каталогом;
- отдельные права для административных операций.

### Проверка конфликтов бронирования

Одной из основных задач является предотвращение двойного бронирования одного ресурса.

Для проверки используются временные интервалы. Два бронирования конфликтуют, если они относятся к одному ресурсу и пересекаются по времени.
